# MediCore HMS Dashboard (Python Flask)

This is a Python Flask web application for a Hospital Management System dashboard. The UI is styled with Bootstrap and matches the provided design screenshot.

## Features
- Sidebar navigation
- Stat cards for patients, appointments, beds, and lab results
- Recent patients and today's appointments tables
- Quick actions
- Responsive layout

## Getting Started
1. Install dependencies:
   ```bash
   pip install flask
   ```
2. Run the app:
   ```bash
   python app.py
   ```
3. Open your browser and go to [http://localhost:5000](http://localhost:5000)

## Customization
- Add real data and endpoints as needed for your HMS workflow.
- Update Bootstrap styles for branding.
